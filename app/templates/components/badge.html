{#- Badges (contracts/components.md §5, FR-028). A status is always a word, so colour is never the only signal: an empty text is refused. -#} {% macro badge(text, kind="neutral") -%} {%- if not text %}{{ template_error("badge: the text is required") }}{% endif -%} {%- set badge_classes = {"success": "badge badge-success", "muted": "badge badge-muted", "neutral": "badge badge-neutral", "info": "badge badge-info", "accent": "badge badge-accent"} -%} {%- if kind not in badge_classes %}{{ template_error("badge: unknown kind " ~ kind) }}{% endif -%} {{ text }} {%- endmacro %} {#- `kind` names the record (milestone 12.5 contracts/components.md §6a), so the Ukrainian word agrees with its noun: «Активний» for a subject, a region and an educational institution, «Активна» for a class (група), «Деактивовано» for all. The contexts are written out per kind, so extraction finds each. -#} {% macro status_badge(is_active, kind) -%} {%- if kind == "subject" %}{% set words = (pgettext("subject", "Active"), pgettext("subject", "Deactivated")) %} {%- elif kind == "region" %}{% set words = (pgettext("region", "Active"), pgettext("region", "Deactivated")) %} {%- elif kind == "institution" %}{% set words = (pgettext("institution", "Active"), pgettext("institution", "Deactivated")) %} {%- elif kind == "class" %}{% set words = (pgettext("class", "Active"), pgettext("class", "Deactivated")) %} {%- else %}{{ template_error("status_badge: unknown kind " ~ kind) }} {%- endif -%} {%- if is_active %}{{ badge(words[0], "success") }}{% else %}{{ badge(words[1], "muted") }}{% endif -%} {%- endmacro %} {% macro access_badge(level) -%} {%- if level == "write" %}{{ badge(pgettext("access level", "Write"), "info") }}{% else %}{{ badge(pgettext("access level", "Read"), "neutral") }}{% endif -%} {%- endmacro %} {#- A competition's status (milestone 12.1 contracts/components.md §3; milestone 12.8 contracts/components.md §1): one word and a kind each, five statuses in the order of the status filter. **Published** (a finished competition whose results are published) uses `accent`, so it stands apart from **Finished** (neutral) and **In progress** (success). It takes the status enum or its value; anything else is refused. -#} {% macro competition_status_badge(status) -%} {%- set value = status | string -%} {%- if value == "upcoming" %}{{ badge(_("Upcoming"), "info") }} {%- elif value == "in_progress" %}{{ badge(_("In progress"), "success") }} {%- elif value == "finished" %}{{ badge(_("Finished"), "neutral") }} {%- elif value == "published" %}{{ badge(_("Published"), "accent") }} {%- elif value == "cancelled" %}{{ badge(_("Cancelled"), "muted") }} {%- else %}{{ template_error("competition_status_badge: unknown status " ~ value) }} {%- endif -%} {%- endmacro %}
