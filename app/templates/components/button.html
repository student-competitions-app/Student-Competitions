{#- Buttons (contracts/components.md §2, FR-025, research D9). Three kinds: primary (Pico's default button), secondary (Pico's `.secondary`) and destructive (`.destructive`, app.css). `outline` and `small` add a class each. A link that opens a form or a confirmation is a `link_button`, styled as the action it leads to. At most one primary per page or section. -#} {% macro _classes(kind, outline, small) -%} {%- set kind_classes = {"primary": "", "secondary": "secondary", "destructive": "destructive"} -%} {%- if kind not in kind_classes %}{{ template_error("button: kind must be primary, secondary or destructive, not " ~ kind) }}{% endif -%} {%- set button_classes = [kind_classes[kind], "outline" if outline else "", "small" if small else ""] | select | join(" ") -%} {{ button_classes }} {%- endmacro %} {#- `busy` renders the busy state, `aria-busy="true"` (milestone 10.1 FR-008, FR-010). Pages never pass it: `loading-feedback.js` marks the button that sent a form while the next page is on its way. It exists so the gallery can show the state. A busy button is never `disabled`, so its value is still sent. -#} {% macro button(label, kind="primary", name=None, value=None, outline=False, small=False, attrs={}, busy=False) -%} {%- set classes = _classes(kind, outline, small) -%} {%- endmacro %} {% macro link_button(label, href, kind="primary", outline=False, small=False) -%} {%- set classes = _classes(kind, outline, small) -%} {{ label }} {%- endmacro %} {% macro post_button(action, label, kind="primary", hidden={}, outline=False, small=False) -%}
