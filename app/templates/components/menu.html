{#- The actions menu (milestone 12.1 contracts/components.md §1, research R14): a row's actions behind one button, a native
like the user menu, so it opens and closes without JavaScript. The button reads "Actions" and is announced "Actions for “”", one whole message in its `aria-label` (milestone 12.5 contracts/components.md §8). The entries come through `{% call %}` as `menu_link`s; when the call block renders only white space, nothing is emitted, so a row with no action has no menu button. `name="row-actions"` makes the menus of a page one exclusive group where the browser supports it: opening one closes the others. Entries are always links to a page (a form or a confirmation), never a `POST`, so every destructive action still goes through its confirmation. Only the gallery passes `open=True`, to show the open panel. A download (milestone 12.8 contracts/components.md §2) is an entry like any other, a link marked as a download (`download=True`): it opens no page, the browser saves the file under the server's name, and the loading script of milestone 10.1 never starts for it (it skips `a[download]`). A download is never destructive. -#} {% macro actions_menu(item_name, open=False) -%} {%- if not item_name %}{{ template_error("actions_menu: the item name is required") }}{% endif -%} {%- set entries = caller() | trim -%} {%- if entries -%}
