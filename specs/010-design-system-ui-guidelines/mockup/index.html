Student Competitions: design mockup

Milestone 10, for the product owner's approval (spec User Story 1). Static and self-contained: open it from the file system, no server, no script, nothing loaded from another site. Each page is shown at 375 px and 1280 px, light and dark. Best viewed in a window at least 1360 px wide. The look of buttons and form controls is drafted here; in the application it comes from Pico.css, restyled through its variables with the same tokens.

0. Identity

The wordmark is text, set in Open Sans 700 beside the mark. The favicon is the same mark with fixed colours.
